# 国庆恶搞页 · "收款码"

一个用来整蛊的国庆祝福页。扫码的人以为要给钱，结果被耍了。

**扫码/访问：** <https://yutian3939.github.io/guoqing/>

## 三段式剧情

1. **假收款页**：头像 + 昵称 + `¥9999.99`，下面是「小奢侈 ¥99 / 很奢侈 ¥999 / 破产级 ¥9999」三档套餐，看着特别像真的要付钱。
2. **付款失败**：自动（或一点就）进入「正在校验你的余额 → 余额检测：十分安全 ✅」进度，然后 `支付失败` 红章盖下来，错误码 `GQ-77`，原因：对方根本没有收款码。
3. **揭晓**：🎉 上当了！→ 国庆快乐 + 「本次成功保住你的 ¥9999.99」，点屏幕任意位置放烟花，还能「再骗一次」（第二次、第三次的台词会变）。

## 说明

- 页面**没有任何输入框、不发起支付、不收集任何信息**，也拿不到任何数据；纯前端玩梗。
- 微信里打开时，标签栏标题先是 `收款 · ¥9999.99`，揭晓后变回 `国庆快乐 ★`。
- 单文件 HTML，零外部依赖（头像已内嵌为 base64），断网也能打开。
- 无 JS 时直接显示祝福，绝不会白屏；在 320 / 360 / 390 / 430px 视口下实测一屏放得下。
