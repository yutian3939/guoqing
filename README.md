# 国庆快乐 · 祝福页 🇨🇳

一个单文件的国庆祝福网页：红金放射背景、飘落五角星、点击任意位置放烟花。

**扫码/访问：** <https://yutian3939.github.io/guoqing/>

## 特点

- 单文件 HTML，零外部依赖，断网也能打开
- 纯 CSS + Canvas 手写动画（烟花、飘星、呼吸标题），无第三方库
- 手机优先：320 / 360 / 390 / 430px 视口下实测无横向溢出，一屏放得下
- 文案默认可见，脚本或动画失效也不会白屏
- 支持 `prefers-reduced-motion`

## 本地预览

```bash
node server.js 8123
# 打开 http://localhost:8123/
```
